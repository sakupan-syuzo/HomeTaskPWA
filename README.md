# 🕰️ ファミリータスク＆置時計ボード (Home Task & Clock PWA)

リビングに常設している **Google Pixel Tablet（横向き・充電スタンド設置）** 等を、**「大型の置時計」兼「家族のルーティン・子どもの用意ボード」** として活用するための Progressive Web App (PWA) です。

フレームワークやビルドツールを一切使わず、**バニラな HTML / CSS / JavaScript のみ**で構築されているため、GitHub Pages などにそのまま置くだけで運用できます。

---

## ✨ 主な機能

### 1. 🕰️ アナログ / デジタル切替対応の大型時計＆全画面スクリーンセーバー
- **ワンタップ切替**：左側の時計エリアをタップするだけで、知育にも適した **「アナログ時計（補助デジタル併記）」** と遠くから見やすい **「超大型デジタル時計」** をいつでも切り替えられます。
- **5分無操作 または「🕒 時計全画面」ボタンで全画面時計モードへ**：5分間操作がないと自動的に画面全体が大きな置時計（スクリーンセーバー）に切り替わります。また、左下の **「🕒 時計全画面」** ボタンを押せば、5分待たずに今すぐ全画面時計に切り替えられます。
- **誤操作防止ガード付き復帰**：全画面時計の表示中に画面のどこをタップしても、裏にあるタスクボタンを誤って押してしまうことなく、安全にタスクボード画面へ復帰します。

### 2. 🎒 子どもの用意（子ども0〜4人対応・項目別ON/OFF・おむつ枚数）
- **保育園・幼稚園・小学校・習い事など幅広く対応**：登園・登校の持ち物チェックや毎日の身支度など、家庭に合わせて項目を自由にカスタマイズできます。
- **0人（なし）〜4人まで選択可能**：
  - **1〜4人**：設定した子どもの人数分（最大4人）の行が一覧で並び、全員分の準備状況が一目で分かります。
  - **0人（なし）**：「子どもの用意」エリアを非表示にし、右側パネル全面を **「🏠 今日の家事・ゴミ出し」専用ボード** として広々使えます。
- **3段階のステータス切替**：各カードは巨大なボタンになっており、タップするたびに以下の3状態で切り替わります。
  1. **未完了**（明るいカード）
  2. **やった / 完了**（✓マーク＋グレーアウト）
  3. **不要**（破線枠でスキップ・その日の進捗計算の分母から自動除外）
- **おむつ必要枚数カウンター**：「🩲 オムツ補充」カード内の `−` `＋` ボタンで、その日に必要な枚数をカード上から直接増減できます。
- **子どもごとの項目 ON / OFF**：上の子はオムツやエプロンをOFFにするなど、子どもごとに表示する持ち物項目を個別にON/OFF設定できます。

### 3. 🏠 今日の家事・ゴミ出し（曜日連動＆前日からの事前表示）
- **曜日別タスク自動表示**：「🔥 燃えるゴミ出し」「🥫 不燃ごみ出し」「♻️ 資源ごみ」や曜日別の家事を、該当する曜日に自動で表示します。
- **前日からの準備表示**：「前日から表示」をONにしたタスクは、前日に **「明日（前日準備）」** バッジ付きで表示され、当日は **「今日」** バッジに切り替わります。

### 4. 🔄 自動リセット機能（ON/OFF切替＆時刻カスタマイズ対応）
- **自動リセットのON/OFF切替**：画面左下のステータスバッジ「自動リセット: ON (4:00)」をタップすると、自動リセット機能のON/OFFを切り替えられます。
  - **ONの場合**：タップするとOFFになり、以降は自動リセットされません（前日の夜に準備した内容が朝になっても消えません）。
  - **OFFの場合**：タップすると時刻設定モーダルが開き、リセット時刻を設定してONにできます。
- **リセット時刻のカスタマイズ**：デフォルトは朝4:00ですが、0:00〜23:59の範囲で自由に設定可能です。
- **論理日付の管理**：設定した時刻を1日の区切りとして記録し、その時刻を跨ぐとすべてのタスクの完了/不要状態が自動的に「未完了」へリセットされます。
- **手動リセット**：画面左下の「🔄 手動リセット」ボタンで、いつでも手動でリセットできます。

### 5. 🌙 暗い部屋で眩しくない自動夜間モード（3段階ハイブリッド制御）
夜間モードでは背景を `#0a0a0a` に落とし、文字盤やカードを落ち着いたアンバー/ウォームグレー系の減光トーンに切り替えます。
1. **第1優先（照度センサー連動）**：`AmbientLightSensor` が有効な環境では、部屋の照明を消して `20 lux` 未満が3秒続くと自動で夜間モードON、明かりをつけて `40 lux` 以上が3秒続くと昼間モードに復帰します（チカチカ防止のヒステリシス制御付き）。ステータスバッジには「テーマ: 輝度優先 (XX lx)」と表示されます。
2. **第2優先（OSテーマ連動）**：センサーが利用できない場合は、端末のダークモード設定（`prefers-color-scheme: dark`）に連動します。ステータスバッジには「テーマ: OS優先」と表示されます。
3. **第3優先（時間帯フォールバック）**：夜間時間帯（21:00〜翌6:00）に入ると自動で夜間モードになります。ステータスバッジには「テーマ: 時間優先」と表示されます。
※画面左下の「🌓 テーマ切替」ボタンで「自動 / 昼固定 / 夜固定」を手動切替することも可能です。
※ステータスバッジで現在どの判定方法が使われているかを一目で確認できます。

### 6. 💡 スリープ防止（Screen Wake Lock API）＆オフライン動作
- `navigator.wakeLock.request('screen')` により、アプリ表示中はタブレットの画面スリープを自動で防止します。
- 設定やタスクデータはすべてブラウザの `localStorage` に保存され、Service Worker によりオフラインでも動作します。

## 📖 使い方マニュアル（画面操作）

### タスクのチェック操作
- **カードをタップ**：`未完了` → `やった (✓)` → `不要` → `未完了` の順に切り替わります。
- **おむつ枚数の変更**：「🩲 オムツ補充」カードの `−` / `＋` ボタンを押すと、カードの完了状態を変えずに必要枚数だけを変更できます。

### 時計の表示切替
- 左側の **時計エリアをタップ** すると、「🕰️ アナログ時計」と「🔢 デジタル時計」が切り替わります。

### 🔄 自動リセットの設定
- 画面左下のステータス表示エリアにある **「自動リセット: ON (4:00)」バッジをタップ** すると、自動リセット機能を設定できます。
  - **現在ONの場合**：タップするとOFFに切り替わります。OFFの間は自動リセットされず、前日の準備内容が保持されます。
  - **現在OFFの場合**：タップすると時刻設定モーダルが開きます。リセットしたい時刻（時・分）を入力して「ONにする」をタップすると、毎日その時刻に自動リセットされるようになります。
- **手動リセット**：いつでも「🔄 手動リセット」ボタンから手動でタスクをリセットできます。

### ⚙️ 設定・タスク編集（画面左下のボタン）
1. **👶 子どもの用意（子ども0〜4人設定）**
   - 「子どもの人数（0人〜4人）」ボタンで表示する人数を変更できます。「0人 (なし)」を選ぶと「子どもの用意」セクションが非表示になり、家庭内タスク（今日の家事・ゴミ出し）だけが表示されます。
   - 1〜4人選択時は、各子どものカードで **名前の変更**、**おむつ必要枚数**、**表示する項目の ON / OFF**（タップで切替）を設定できます。
2. **🗑️ ゴミ出し曜日設定**
   - 「🔥 燃えるゴミ出し」「🥫 不燃ごみ出し」「♻️ 資源ごみ」の収集曜日（月〜日）と、「前日から表示」のON/OFFを設定できます。
3. **➕ タスク項目の追加・削除**
   - アイコン（絵文字プリセットまたは自由入力）、タスク名、追加先カテゴリ（子どもの用意 / 今日の家事）、表示曜日、「前日も表示する」を選んで新しいタスクを追加できます。
   - 下部のリストから不要なタスクの「削除」や、「初期サンプルに戻す」ことも可能です。

## 📱 Google Pixel Tablet（Android Chrome）での初期セットアップ

### 1. ホーム画面へインストール（PWA化）
1. GitHub Pages などの公開URL（`https://...`）を Pixel Tablet の Chrome で開きます。
2. 画面左下に表示される **「📲 アプリをインストール」** ボタンをタップするか、Chrome右上のメニュー「**⋮**」→ **「アプリをインストール（ホーム画面に追加）」** を選択します。
3. ホーム画面に追加された **「タスク時計」** アイコンから起動すると、アドレスバーのない横向きフル画面で動作します。

### 2. 照度センサー（AmbientLightSensor）を有効にする場合（任意）
リビングの照明の消灯・点灯をルクス（lx）値で直接検知させたい場合は、Chromeの試験運用フラグをONにします。
（※設定しなくても、OSのダークテーマや21:00〜翌6:00の時間帯判定で自動的に夜間モードになります）

1. Chromeのアドレスバーに以下を入力して開きます：
   ```text
   chrome://flags/#enable-experimental-web-platform-features
   ```
2. **「Experimental Web Platform features」** を **`Enabled`** に変更し、右下の **「Relaunch（再起動）」** をタップします。
3. Chromeの「設定」→「サイトの設定」→「モーション センサー（またはセンサー）」が許可されていることを確認してください。
4. 正常に有効化されると、アプリ左下のバッジに `照度: ○○ lx (明室/暗室)` とリアルタイムの明るさが表示されます。

## 📁 ファイル構成

```text
.
├── index.html     # メイン画面・モーダル・全画面スクリーンセーバー構造
├── style.css      # タブレット横向き特化レイアウト・昼/夜（減光）テーマ定義
├── app.js         # 時計制御・タスク管理・LocalStorage永続化・Wake Lock・照度センサー制御
├── manifest.json  # PWAマニフェスト設定（standalone / landscape指定）
├── sw.js          # オフラインキャッシュ用 Service Worker
├── icon-192.png   # PWAアプリアイコン (192x192)
├── icon-512.png   # PWAアプリアイコン (512x512)
└── icon.svg       # ベクターアイコン
```

# 🕰️ ファミリータスク＆置時計ボード (Home Task & Clock PWA)

リビングに常設している **Google Pixel Tablet（横向き・充電スタンド設置）** 等を、**「大型の置時計」兼「家族のルーティン・子どもの用意ボード」** として活用するための Progressive Web App (PWA) です。

フレームワークやビルドツールを一切使わず、**バニラな HTML / CSS / JavaScript のみ**で構築されているため、GitHub Pages などにそのまま置くだけで運用できます。

---

## ✨ 主な機能

### 1. 🕰️ アナログ / デジタル切替対応の大型時計＆全画面スクリーンセーバー
- **ワンタップ切替**：左側の時計エリアをタップするだけで、知育にも適した **「アナログ時計（補助デジタル併記）」** と遠くから見やすい **「超大型デジタル時計」** をいつでも切り替えられます。
- **5分無操作 または「🕒 時計全画面」ボタンで全画面時計モードへ**：5分間操作がないと自動的に画面全体が大きな置時計（スクリーンセーバー）に切り替わります。また、左下の **「🕒 時計全画面」** ボタンを押せば、5分待たずに今すぐ全画面時計に切り替えられます。
- **誤操作防止ガード付き復帰**：全画面時計の表示中に画面のどこをタップしても、裏にあるタスクボタンを誤って押してしまうことなく、安全にタスクボード画面へ復帰します。

### 2. 🎒 子どもの用意（子ども0〜4人対応・項目別ON/OFF・おむつ枚数入力）
- **保育園・幼稚園・小学校・習い事など幅広く対応**：登園・登校の持ち物チェックや毎日の身支度など、家庭に合わせて項目を自由にカスタマイズできます。
- **0人（なし）〜4人まで選択可能**：
  - **1〜4人**：設定した子どもの人数分（最大4人）の行が一覧で並び、全員分の準備状況が一目で分かります。
  - **0人（なし）**：「子どもの用意」エリアを非表示にし、右側パネル全面を **「🏠 今日の家事・ゴミ出し」専用ボード** として広々使えます。
- **3段階のステータス切替**（おむつは次の項目のとおり、動作が異なります）：各カードは巨大なボタンになっており、タップするたびに以下の3状態で切り替わります。
  1. **未完了**（明るいカード）
  2. **やった / 完了**（✓マーク＋グレーアウト）
  3. **不要**（破線枠でスキップ・その日の進捗計算の分母から自動除外）
- **おむつ枚数入力**：「🩲 オムツ補充」カードは、次のように動作します。
  - 未入力のカードをタップすると、0〜10の入力パネルが開きます。
  - 入力すると「必要 ○ 枚」と表示され、以降はカードをタップして「未完了」と「やった」を切り替えます。
  - 「不要」にしたいときは、0を入力します（「今回は不要」と表示され、進捗の分母から外れます）。
  - 枚数を変えるときは、枚数の部分をタップします。枚数を変えると、状態は未完了に戻ります。
  - 入力した枚数と状態は、戻り時刻（初期値15:00）を過ぎると自動的に消えます（日付の区切り時刻では消えません）。
  - おむつを卒業した子は、設定画面の子どもごとの項目ON/OFFでOFFにできます。
- **子どもごとの項目 ON / OFF**：上の子はオムツやエプロンをOFFにするなど、子どもごとに表示する持ち物項目を個別にON/OFF設定できます。

### 3. 🏠 今日の家事・ゴミ出し（曜日連動＆前日からの事前表示）
- **曜日別タスク自動表示**：「🔥 燃えるゴミ出し」「🥫 不燃ごみ出し」「♻️ 資源ごみ」や曜日別の家事を、該当する曜日に自動で表示します。
- **前日からの準備表示**：「前日から表示」をONにしたタスクは、前日に **「明日（前日準備）」** バッジ付きで表示され、当日は **「今日」** バッジに切り替わります。

### 4. 🔄 日付の区切り時刻と状態管理
- **日付の区切り時刻の設定**：画面左下のステータスバッジ「日付の区切り: 04:00」をタップして設定します（初期値4:00、0:00〜23:59）。
- **区切り時刻より前は前日として扱う**：区切り時刻より前は、前日として扱います。例：火曜の2:00は、月曜のタスクが表示されます。時計と日付は、実際の時刻のままです。
- **状態ごとに対象日を記録**：タスクを「完了」や「不要」にすると、その状態と対象日が記録されます。日付が切り替わっても、状態は一括では消えません。前日準備として記録した状態は、設定に応じて当日に引き継がれます。
- **前日表示と引き継ぎの違い**：
  - **引き継がない例（ゴミ出し）**：「前日から表示」をONにすると、前日には「明日（前日準備）」として表示され、当日に「今日」に切り替わります。前日に準備した状態と当日の状態は別々に記録されるため、前日に準備しても当日は未完了として表示されます。
  - **引き継ぐ例（お昼寝シーツ）**：「前日のチェックを引き継ぐ」をONにすると、前日に準備した「完了」状態が当日にも引き継がれます。
  - 引き継ぐ設定の初期値は、ゴミ出しはオフ、それ以外のタスクはオンです。設定画面で、タスクごとに変更できます。
- **手動リセット**：画面左下の「🔄 手動リセット」ボタンで、今日分と前日準備（明日）分の状態を未完了に戻し、おむつの入力値も未入力に戻します。

### 5. 🌙 暗い部屋で眩しくない自動夜間モード（2段階制御）
夜間モードでは背景を `#0a0a0a` に落とし、文字盤やカードを落ち着いたアンバー/ウォームグレー系の減光トーンに切り替えます。
1. **第1優先（照度センサー連動）**：`AmbientLightSensor` が有効な環境では、部屋の照明を消して `20 lux` 未満が3秒続くと自動で夜間モードON、明かりをつけて `40 lux` 以上が3秒続くと昼間モードに復帰します（チカチカ防止のヒステリシス制御付き）。ステータスバッジには「テーマ: 照度 (XX lx)」と表示されます。
2. **第2優先（時間帯フォールバック）**：センサーが利用できない場合は、夜間時間帯（21:00〜翌6:00）で自動的に夜間モードになります。ステータスバッジには「テーマ: 時間帯」と表示されます。
※OSのダークモード設定は使用しません。
※画面左下の「🌓 テーマ切替」ボタンで「自動 / 昼固定 / 夜固定」を手動切替することも可能です。
※ステータスバッジで現在どの判定方法が使われているかを一目で確認できます。

### 6. 💡 スリープ防止（Screen Wake Lock API）＆オフライン動作
- `navigator.wakeLock.request('screen')` により、アプリ表示中はタブレットの画面スリープを自動で防止します。
- 設定やタスクデータはすべてブラウザの `localStorage` に保存され、Service Worker によりオフラインでも動作します。

## 📖 使い方マニュアル（画面操作）

### タスクのチェック操作
- **カードをタップ**（おむつ以外のタスク）：`未完了` → `やった (✓)` → `不要` → `未完了` の順に切り替わります。
- **おむつ枚数の入力**：
  - 未入力のカードをタップすると、0〜10の入力パネルが開きます。
  - 入力すると「必要 ○ 枚」と表示され、以降はカードをタップして「未完了」と「やった」を切り替えます。
  - 「不要」にしたいときは、0を入力します（「今回は不要」と表示され、進捗の分母から外れます）。
  - 枚数を変えるときは、枚数の部分をタップします。枚数を変えると、状態は未完了に戻ります。
- **スクロール表示**：リストの内容が画面に収まらない場合は、右側にスクロールバーが表示されます。

### 時計の表示切替
- 左側の **時計エリアをタップ** すると、「🕰️ アナログ時計」と「🔢 デジタル時計」が切り替わります。

### 🔄 日付の区切り時刻の設定
- 画面左下のステータス表示エリアにある **「日付の区切り: 04:00」バッジをタップ** して設定します（初期値4:00、0:00〜23:59）。
- 区切り時刻より前は、前日として扱います。例：火曜の2:00は、月曜のタスクが表示されます。時計と日付は、実際の時刻のままです。
- 日付が切り替わっても、状態は一括では消えません。前日準備として記録した状態は、設定に応じて当日に引き継がれます。
- **手動リセット**：いつでも「🔄 手動リセット」ボタンから、今日分と前日準備（明日）分の状態を未完了に戻し、おむつの入力値も未入力に戻せます。

### ⚙️ 設定・タスク編集（画面左下のボタン）
1. **👶 子どもの用意（子ども0〜4人設定）**
   - 「子どもの人数（0人〜4人）」ボタンで表示する人数を変更できます。「0人 (なし)」を選ぶと「子どもの用意」セクションが非表示になり、家庭内タスク（今日の家事・ゴミ出し）だけが表示されます。
   - 1〜4人選択時は、各子どものカードで **名前の変更**、**表示する項目の ON / OFF**（タップで切替）を設定できます。
2. **🗑️ ゴミ出し曜日設定**
   - 「🔥 燃えるゴミ出し」「🥫 不燃ごみ出し」「♻️ 資源ごみ」の収集曜日（月〜日）、「前日から表示」のON/OFF、「前日のチェックを引き継ぐ」のON/OFFを設定できます。
3. **🩲 おむつの戻り時刻**
   - おむつの入力値と状態が消えて、未入力に戻る時刻です（初期値15:00）。
   - 入力した後で最初に来る戻り時刻まで有効です。例：月曜21:00に入力 → 火曜15:00まで有効。
   - 日付の区切り時刻（初期値4:00）とは別に管理しています。
4. **➕ タスク項目の追加・削除**
   - アイコン（絵文字プリセットまたは自由入力）、タスク名、追加先カテゴリ（子どもの用意 / 今日の家事）、表示曜日、「前日も表示する」、「前日のチェックを引き継ぐ」を選んで新しいタスクを追加できます。
   - 下部のリストから不要なタスクの「削除」や、「初期サンプルに戻す」ことも可能です。

## 📱 Google Pixel Tablet（Android Chrome）での初期セットアップ

### 1. ホーム画面へインストール（PWA化）
1. GitHub Pages などの公開URL（`https://...`）を Pixel Tablet の Chrome で開きます。
2. 画面左下に表示される **「📲 アプリをインストール」** ボタンをタップするか、Chrome右上のメニュー「**⋮**」→ **「アプリをインストール（ホーム画面に追加）」** を選択します。
3. ホーム画面に追加された **「タスク時計」** アイコンから起動すると、アドレスバーのない横向きフル画面で動作します。

### 2. 照度センサー（AmbientLightSensor）を有効にする場合（任意）
リビングの照明の消灯・点灯をルクス（lx）値で直接検知させたい場合は、Chromeの試験運用フラグをONにします。
（※設定しなくても、21:00〜翌6:00の時間帯判定で自動的に夜間モードになります）

1. Chromeのアドレスバーに以下を入力して開きます：
   ```text
   chrome://flags/#enable-experimental-web-platform-features
   ```
2. **「Experimental Web Platform features」** を **`Enabled`** に変更し、右下の **「Relaunch（再起動）」** をタップします。
3. Chromeの「設定」→「サイトの設定」→「モーション センサー（またはセンサー）」が許可されていることを確認してください。
4. 正常に有効化されると、アプリ左下のバッジに `テーマ: 照度 (○○ lx)` とリアルタイムの明るさが表示されます。

## 🧑‍💻 開発者向け

### テストモード（時刻指定＆データ分離）
- **`?now=YYYY-MM-DDTHH:mm:ss`** でURLを開くと、指定した時刻で動作確認できます（例：`?now=2026-10-20T15:00`）。
- **`&testreset=1`** を追加すると、テストモード用のデータをクリアして通常データのコピーから再開できます。
- テストモード中はすべてのデータが `test_` 付きのキーに保存され、本番のデータには影響しません。
- **テストモードの注意点**：
  - `?now=` で時刻を変えて確認するときは、古い時刻から新しい時刻の順に開きます（時刻を戻すと、状態が正しく確認できません）。
  - `&testreset=1` は、最初に開くURLだけに付けます。付けたままだと、再読み込みのたびにテスト用データが作り直されます。
  - 開発者ツールの Application → Service workers で「Update on reload」にチェックを入れて確認します（古い app.js が使われるのを防ぐため）。
  - 操作する前に、画面に「TEST MODE」と表示されているか確認します。

### 更新時の注意
- `sw.js` のキャッシュバージョン（`CACHE_NAME`）を上げないと、ブラウザが古いファイルを読み続けることがあります。

## 📁 ファイル構成

```text
.
├── index.html     # メイン画面・モーダル・全画面スクリーンセーバー構造
├── style.css      # タブレット横向き特化レイアウト・昼/夜（減光）テーマ定義
├── app.js         # 時計制御・タスク管理・LocalStorage永続化・Wake Lock・照度センサー制御
├── manifest.json  # PWAマニフェスト設定（standalone / landscape指定）
├── sw.js          # オフラインキャッシュ用 Service Worker
├── icon-192.png   # PWAアプリアイコン (192x192)
├── icon-512.png   # PWAアプリアイコン (512x512)
```
